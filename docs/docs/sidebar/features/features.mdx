# Features

osapi manages Linux and macOS hosts. Each feature page tells what osapi does in
one subject, how to use it from the CLI, the API, the SDK and the UI, and the
settings and permissions that it needs.

The feature pages are in a group for each area, in the order of the tabs of the
Configure page of the UI and the [SDK](../sdk/client/client.md). The platform
pages, such as authentication and the job system, are last. They tell how osapi
works for each area.
