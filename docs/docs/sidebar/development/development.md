# Development

[`CONTRIBUTING.md`][contributing], at the root of the repository, gives the
prerequisites, the setup, the build, the code style, the code standards, the
tests and input validation.

That file is the single source, so this page is a pointer rather than a second
copy of it.

This section has three more guides. Each one is about a subject, not about how
to contribute:

- [UI Development](ui-development.md): the rules of the React dashboard, and
  where its commands are.
- [Your first behavior](your-first-behavior.md): a tutorial that builds a new
  behavior, from its types to a command that runs.
- [Building a behavior](behaviors.md): every option, tag and generated file.
