# Development

Prerequisites, setup, building, code style, code standards, testing, and input
validation all live in [`CONTRIBUTING.md`][contributing] at the repository root.

That file is the single source, so this page is a pointer rather than a second
copy of it.

Three guides remain in this section, because each covers a subject rather than
the act of contributing:

- [UI Development](ui-development.md): the rules the React dashboard is built
  under, and where its commands live.
- [Your first behavior](your-first-behavior.md): a tutorial that builds a
  behavior from scratch, from its types to a running command.
- [Building a behavior](behaviors.md): every option, tag and generated file.
