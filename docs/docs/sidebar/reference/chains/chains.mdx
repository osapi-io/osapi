# Chains

A behavior that requires others calls them on the same host, in the same job.
The behaviors that it calls, and the ones that those call, are its chain. The
page of each chain shows each call that the examples of its behavior make, with
what each call sends and gets. The [Chains DSL](../../development/dsl/chain.md)
tells how to build one.
[Behavior chains](../../features/platform/behavior-chains.md) tells what a
caller sees when a chain runs, and what occurs when a step fails.

## Every behavior in a chain in this build

<Catalog />

A behavior that calls others has a chain page, which **Behavior** links to. A
behavior that only others call, such as `managedfile`, links to its behavior
page. **Used by** shows the behaviors that call it.

The pages are in a folder for each area, the area of the behavior at the top of
the chain. An internal behavior has no area, and its folder is last.
