# SDK

OSAPI has a Go SDK for programmatic access to the REST API: a typed client with
a service for each group of the API. The services are in a group for each area,
in the order of the Behaviors page of the UI and the feature pages. The client's
overview, the guidelines and platform detection are last. For DAG-based task
orchestration, see
[osapi-orchestrator](https://github.com/osapi-io/osapi-orchestrator).
