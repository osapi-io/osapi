# Behavior

List, describe and validate the behaviors this binary has.

A behavior is one thing osapi manages on a host, such as kernel parameters; see
[Behaviors](../../../architecture/behaviors.md). These commands read the
definitions in the binary. Thus they need no config file and no controller. What
they print always agrees with the build that you run.
