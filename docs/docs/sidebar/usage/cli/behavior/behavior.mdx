# Behavior

CLI to list, describe and check the behaviors this binary has, and to start a
new one. A behavior is one thing osapi manages on a host, such as kernel
parameters; see [Behaviors](../../../architecture/behaviors.md). These commands
read the definitions compiled into the binary, so they need no config file and
no controller, and what they print always matches the build you run.
