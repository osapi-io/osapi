# CLI

Typed, repeatable operations for Linux and macOS hosts.

| Command            | Purpose                                                                        |
| ------------------ | ------------------------------------------------------------------------------ |
| `osapi agent`      | Run the agent on this host, and work on its key                                |
| `osapi client`     | Call the API of the controller                                                 |
| `osapi config`     | List, get and validate the config that each component reads                    |
| `osapi controller` | Run the controller on this host, and work on its key, its tokens and its roles |
| `osapi dsl`        | Describe, check and document the definitions of osapi, for authors             |
| `osapi nats`       | Run the embedded NATS server on this host, or prepare a NATS server            |
| `osapi skill`      | Show the agent skills in this binary, and install them into a repository       |
| `osapi start`      | Start each component of osapi on this host                                     |
| `osapi version`    | Show the version of this binary                                                |

## Flags

| Flag               | Description                  | Default                 |
| ------------------ | ---------------------------- | ----------------------- |
| `-d, --debug`      | Enable or disable debug mode |                         |
| `-j, --json`       | Enable JSON output           |                         |
| `-f, --osapi-file` | Path to config file          | `/etc/osapi/osapi.yaml` |
