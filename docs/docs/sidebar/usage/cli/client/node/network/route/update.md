# Update

Change the routes osapi has of an interface.

Writes the interface's routes file over the one osapi has, as create writes it,
and applies it. An interface osapi has no routes of is not found: create adds
them.

```bash
osapi client node network route update [flags]
```

## Examples

```bash
# One route in place of two
osapi client node network route update --target web-01 --interface-name osapi0 --routes "203.0.113.0/24 via 192.0.2.1 metric 10"
```

## Permission

It needs the `network:write` permission. `osapi token roles get --name <role>`
shows what a role grants.

## Flags

| Flag               | Description                                                                                                                                                                           | Default |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- |
| `--interface-name` | The interface, such as eth0, or a fact such as @fact.interface.primary (required)                                                                                                     |         |
| `--routes`         | Each route as ip route writes it: &lt;destination&gt; via &lt;gateway&gt;, with metric &lt;n&gt; after it when you give one, such as 10.0.0.0/8 via 192.168.1.1 metric 100 (required) |         |
| `-T, --target`     | Target: _all, _any, hostname, or label (group:web.dev)                                                                                                                                | `_all`  |

## Global flags

| Flag               | Description                    | Default                 |
| ------------------ | ------------------------------ | ----------------------- |
| `-d, --debug`      | Enable or disable debug mode   |                         |
| `-j, --json`       | Enable JSON output             |                         |
| `-f, --osapi-file` | Path to config file            | `/etc/osapi/osapi.yaml` |
| `--url`            | URL the client will connect to | `http://0.0.0.0:8080`   |

[Output](../../../../output.md) tells how the result is printed, and what
`--json` gives.
