# Delete

Remove a group.

Removes the group with groupdel. A group that the host does not have does not
change and reports changed: false. It runs on the Debian family only, and
elsewhere reports skipped.

```bash
osapi client node group delete [flags]
```

## Examples

```bash
# Remove a group
osapi client node group delete --target web-01 --name osapitest

# A group that the host does not have
osapi client node group delete --target web-01 --name osapitest
```

With the default settings, each example does this on the host:

| Example        | On the host                  |
| -------------- | ---------------------------- |
| Remove a group | runs `groupdel -- osapitest` |

The command fails in these cases:

| Call                             | Flags                                      | Fails with   |
| -------------------------------- | ------------------------------------------ | ------------ |
| A name that is an option         | `--name -r`                                | account_name |
| A name longer than 32 characters | `--name aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa` | max          |

## Permission

It needs the `group:write` permission. `osapi token roles get --name <role>`
shows what a role grants.

## Flags

| Flag           | Description                                            | Default |
| -------------- | ------------------------------------------------------ | ------- |
| `--name`       | The group to remove, such as developers (required)     |         |
| `-T, --target` | Target: _all, _any, hostname, or label (group:web.dev) | `_all`  |

## Global flags

| Flag               | Description                    | Default                 |
| ------------------ | ------------------------------ | ----------------------- |
| `-d, --debug`      | Enable or disable debug mode   |                         |
| `-j, --json`       | Enable JSON output             |                         |
| `-f, --osapi-file` | Path to config file            | `/etc/osapi/osapi.yaml` |
| `--url`            | URL the client will connect to | `http://0.0.0.0:8080`   |

[Output](../../../output.md) tells how the result is printed, and what `--json`
gives.
