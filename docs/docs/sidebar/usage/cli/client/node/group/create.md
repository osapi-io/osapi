# Create

Add a group.

Adds the group with groupadd, with the ID when one is given. A group that the
host has already does not change and reports changed: false, whatever its ID. It
runs on the Debian family only, and elsewhere reports skipped.

```bash
osapi client node group create [flags]
```

## Examples

```bash
# Add a group
osapi client node group create --target web-01 --name osapitest

# Add a system group with its ID
osapi client node group create --target web-01 --name osapitest --gid 1999 --system

# A group that the host has
osapi client node group create --target web-01 --name developers
```

With the default settings, each example does this on the host:

| Example                        | On the host                             |
| ------------------------------ | --------------------------------------- |
| Add a group                    | runs `groupadd -- osapitest`            |
| Add a system group with its ID | runs `groupadd -g 1999 -r -- osapitest` |

The command fails in these cases:

| Call                             | Flags                                      | Fails with   |
| -------------------------------- | ------------------------------------------ | ------------ |
| A name that is an option         | `--name -r`                                | account_name |
| A name longer than 32 characters | `--name aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa` | max          |
| A negative ID                    | `--name osapitest --gid -1`                | min          |

## Permission

It needs the `group:write` permission. `osapi token roles get --name <role>`
shows what a role grants.

## Flags

| Flag           | Description                                                | Default |
| -------------- | ---------------------------------------------------------- | ------- |
| `--gid`        | Its numeric group ID; the system assigns one when it is 0  |         |
| `--name`       | The group to add, such as developers (required)            |         |
| `--system`     | Add it as a system group, with an ID from the system range |         |
| `-T, --target` | Target: _all, _any, hostname, or label (group:web.dev)     | `_all`  |

## Global flags

| Flag               | Description                    | Default                 |
| ------------------ | ------------------------------ | ----------------------- |
| `-d, --debug`      | Enable or disable debug mode   |                         |
| `-j, --json`       | Enable JSON output             |                         |
| `-f, --osapi-file` | Path to config file            | `/etc/osapi/osapi.yaml` |
| `--url`            | URL the client will connect to | `http://0.0.0.0:8080`   |

[Output](../../../output.md) tells how the result is printed, and what `--json`
gives.
