# Node

Send jobs to the agents of target hosts.

These commands send jobs to the agents of the target host. To find the agents in
the registry, refer to the [Agent](../agent/agent.mdx) commands.

## Flags

| Flag           | Description                                              | Default |
| -------------- | -------------------------------------------------------- | ------- |
| `-T, --target` | Target: \_all, \_any, hostname, or label (group:web.dev) | `_all`  |
