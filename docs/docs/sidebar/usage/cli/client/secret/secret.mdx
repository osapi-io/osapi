# Secret

Manage the secrets in the vaults of the controller.

A secret is a key in a vault of the controller. A request uses it as a
reference, secret://&lt;vault&gt;/&lt;key&gt;. These commands write a value and
read the metadata of each key. Only reveal shows a value, with secret:reveal,
which only the admin role has.
