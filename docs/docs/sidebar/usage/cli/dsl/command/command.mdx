# Command

List, describe and validate the local commands, and print their DSL.

A local command runs in the CLI process and calls no API, such as
`osapi controller token generate`. Its group is a definition in
`internal/cli/commands/<group>`, and its commands, flags, help and pages come
from it. A command that calls the API is an endpoint (`osapi dsl endpoint`) or a
behavior (`osapi dsl behavior`). These commands read the definitions in the
binary. Thus they need no config file and no running controller.
