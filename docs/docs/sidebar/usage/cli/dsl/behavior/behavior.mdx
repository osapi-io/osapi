# Behavior

List, describe and validate the behaviors this binary has.

A behavior is one thing that osapi manages on a host, for example kernel
parameters. \[Behaviors](../../../../architecture/behaviors.md) tells more.
These commands read the definitions in the binary. Thus they need no config file
and no controller. What they print always agrees with the build that you run.
