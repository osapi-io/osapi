# Agent

Run the agent on this host, and work on its key.

The agent runs on each managed host, processes jobs, and reports status back to
the control plane.

## Flags

| Flag           | Description                                                                                                             | Default         |
| -------------- | ----------------------------------------------------------------------------------------------------------------------- | --------------- |
| `--sysctl-dir` | Directory the agent writes osapi's kernel parameter files to, one osapi-&lt;key&gt;.conf per key (behaviors.sysctl.dir) | `/etc/sysctl.d` |
