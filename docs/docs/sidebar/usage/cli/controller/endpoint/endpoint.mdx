# Endpoint

List, describe and validate the controller's own endpoints, and print their DSL.

An endpoint is one operation of the controller itself, such as `GET /api/agent`.
It runs on the controller, not on a host. Work on a host is a behavior: see
`osapi behavior`. These commands read the definitions in the binary. Thus they
need no config file and no running controller.

`spec` lists each part of the DSL. The groups are defined, and their specs are
compared with the hand-written specs. The controller still serves the
hand-written specs.
