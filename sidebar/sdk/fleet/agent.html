Agent

c.Agent calls the API's Agent group. Operations related to agent discovery and details.

List​

func (s *AgentService) List(
	ctx context.Context,
) (*Response[ListAgentsResponse], error)

List active agents.

Discover all active agents in the fleet.

It sends GET /api/agent, and needs the permission agent:read.

The examples of the method's definition:

List active agents, go run agent.go list:

resp, err := c.Agent.List(ctx)

Facts​

func (s *AgentService) Facts(
	ctx context.Context,
) (*Response[FactKeysResponse], error)

List the fact keys.

Returns the fact keys that an input can refer to as @fact.: the built-in keys and the custom keys that agents register.

It sends GET /api/agent/facts, and needs the permission agent:read.

The examples of the method's definition:

List the fact keys, go run agent.go facts:

resp, err := c.Agent.Facts(ctx)

Join​

func (s *AgentService) Join(
	ctx context.Context,
	input AgentJoinInput,
) (*Response[JoinResponse], error)

Join an agent with a join token.

An agent calls it one time, at its first start, over HTTPS, after it checks the controller's certificate against the fingerprint of its join string. A token that admits admits the machine at once, as admit does, and the admission record names the token. The request is signed with the agent's signing key, which shows that it holds the key that it asks the controller to admit. It needs no bearer token: the join token authorizes it.

It sends POST /api/agent/join, and needs no permission.

Get​

func (s *AgentService) Get(
	ctx context.Context,
	hostname string,
) (*Response[AgentInfo], error)

Get agent details.

Get detailed information about a specific agent by hostname.

It sends GET /api/agent/{hostname}, and needs the permission agent:read.

The examples of the method's definition:

Get agent details, go run agent.go get:

resp, err := c.Agent.Get(ctx, "web-01")

Drain​

func (s *AgentService) Drain(
	ctx context.Context,
	hostname string,
) error

Drain an agent.

Stop the agent from accepting new jobs. In-flight jobs continue to completion.

It sends POST /api/agent/{hostname}/drain, and needs the permission agent:write.

The examples of the method's definition:

Drain an agent, go run agent.go drain:

err := c.Agent.Drain(ctx, "web-01")

Undrain​

func (s *AgentService) Undrain(
	ctx context.Context,
	hostname string,
) error

Undrain an agent.

Resume accepting jobs on a drained agent.

It sends POST /api/agent/{hostname}/undrain, and needs the permission agent:write.

The examples of the method's definition:

Undrain an agent, go run agent.go undrain:

err := c.Agent.Undrain(ctx, "web-01")
