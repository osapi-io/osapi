Catalog

c.Catalog calls the API's Catalog group. The behaviors, the permissions and the roles that the controller serves, for the UI.

Methods​

MethodReturnsPermissionDescription
Get(ctx)*Response[CatalogResponse]catalog:readGet the catalog.

Get​

func (s *CatalogService) Get(
	ctx context.Context,
) (*Response[CatalogResponse], error)

Get the catalog.

Returns each behavior with its methods, the areas, the permissions, the built-in roles, the permission of each operation, the tones of the statuses and the counts, and the host families. The UI reads it after sign-in. Each built-in role has catalog:read.

It sends GET /api/catalog, and needs the permission catalog:read.

The examples of the method's definition:

Get the catalog, go run catalog.go get:

resp, err := c.Catalog.Get(ctx)

CatalogResponse​

FieldTypeDescription
Areas[]CatalogAreaEach area, in order, with its label.
Behaviors[]CatalogBehaviorEach behavior that the API serves, and each internal behavior, in the order of the registry.
Controller[]CatalogControllerMethodEach method of an endpoint group of the Object Store area: a call of the controller that takes no target.
CountTonesmap[string]stringThe tone of a count above zero, by what it counts: ok, warn or err.
HostFamilies[]stringThe host platforms that gohai names. A method's runs_on has * for any other Linux.
Operations[]CatalogOperationThe permission of each operation that needs one, in the order of the operationIds.
Outcomes[]stringThe outcomes of a host, from the best to the worst, as the CLI's summary orders them.
Permissions[]PermissionEach permission that osapi knows.
RenderTags[]stringThe render tags of an output field, as the CLI reads them. short= takes a number, such as short=12.
Roles[]CatalogRoleThe built-in roles, in order, with the permissions of each.
StatusTonesmap[string]stringThe tone of each status word, as the CLI colors it: ok, warn or err.
Targets[]CatalogTargetThe targets that name no host: each agent, or any one agent.

A string, one of read, write, action.
