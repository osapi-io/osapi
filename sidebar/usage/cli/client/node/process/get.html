Get

Get one process.

Reads one process by its ID, without the others. A process that the host does not have is not found.

osapi client node process get [flags]

Examples​

# A process of a Linux host
osapi client node process get --target web-01 --pid 1234

# A process of a Mac
osapi client node process get --target web-01 --pid 1234

Result​

A process of a Linux host, on one host:

Results:

$ osapi client node process get --target _all --pid 1234

The command fails in these cases:

CallFlagsFails with
A process that the host does not have--pid 99999not found
A process ID below 1--pid -1min

Permission​

It needs the process:read permission. osapi controller role get --name <role> shows what a role grants.

Flags​

FlagDescriptionDefault
--pidThe process ID, such as 1234 (required)
-T, --targetTarget: _all, _any, hostname, or label (group:web.dev)_all

Global flags​

FlagDescriptionDefault
-d, --debugEnable or disable debug mode
-j, --jsonEnable JSON output
-f, --osapi-filePath to config file/etc/osapi/osapi.yaml
--urlURL the client will connect tohttp://0.0.0.0:8080

Output tells how the result is printed, and what --json gives.
