Get

Print the config file: each key, what it does, its type, default and rules.

The list comes from this binary. Thus it agrees with the build that you run. A section for each top word of a key, such as controller. osapi config get --key <key> shows one key with its value in effect.

osapi config spec get

Examples​

osapi config spec get
osapi config spec get --json

Result​

The command prints:

$ osapi config spec get
controller:
  controller.client.url
    Base URL the CLI client connects to. Type: string. Default:
    http://0.0.0.0:8080.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_CLIENT_URL, which wins over
    the file.

  controller.client.security.bearer_token
    JWT bearer token for client requests (required). Generate with osapi
    controller token generate. It can be a reference,
    secret://<vault>/<key>, which the command resolves from the vaults of
    its config. Type: string.
    Use: In osapi.yaml, or with
    OSAPI_CONTROLLER_CLIENT_SECURITY_BEARER_TOKEN, which wins over the file.
    Rules: required. A secret: osapi prints it as ********.

  controller.client.tls.ca_file
    A PEM certificate that the CLI trusts on an https:// URL, such as
    api.crt of a controller with a self-signed certificate, in its
    controller.pki.key_dir. Without it, the system's trusted roots. Type:
    string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_CLIENT_TLS_CA_FILE, which
    wins over the file.

  controller.api.host
    Host the REST API server, and the UI on its listener, binds to. Empty
    binds every interface. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_API_HOST, which wins over
    the file.

  controller.api.url
    Where a person reaches the API, shown by health beside the bind address.
    Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_API_URL, which wins over
    the file. Rules: omitempty,http_url.

  controller.api.port
    Port the REST API server listens on. Type: int. Default: 8080.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_API_PORT, which wins over
    the file. Rules: min=1,max=65535.

  controller.api.security.cors.allow_origins
    Origins allowed to make cross-origin requests. An empty list disables
    CORS headers entirely. Type: list.
    Use: In osapi.yaml, or with
    OSAPI_CONTROLLER_API_SECURITY_CORS_ALLOW_ORIGINS, which wins over the
    file.

  controller.api.security.signing_keys
    HS256 keys for JWTs, each an id and a key (required). The first key
    signs; each key verifies the tokens with its id as kid. The environment
    variable takes id=key pairs with commas between them. Generate a key
    with openssl rand -hex 32. A key can be a reference,
    secret://<vault>/<key>, which the controller resolves at startup. Type:
    list.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_API_SECURITY_SIGNING_KEYS,
    which wins over the file. Rules: required,min=1,unique=ID,dive. A
    secret: osapi prints it as ********.

  controller.api.security.roles
    Custom roles with fine-grained permissions. Type: map.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_API_SECURITY_ROLES, which
    wins over the file. Rules: dive.

  controller.api.tls.enabled
    Serve HTTPS on the API's port, in place of HTTP. Without cert_file and
    key_file, the controller makes a self-signed certificate in
    controller.pki.key_dir. Type: bool.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_API_TLS_ENABLED, which wins
    over the file.

  controller.api.tls.cert_file
    The PEM certificate to serve, with its chain, such as one from tailscale
    cert or certbot. Set it with key_file, or neither for the self-signed
    certificate. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_API_TLS_CERT_FILE, which
    wins over the file. Rules: required_with=KeyFile.

  controller.api.tls.key_file
    The PEM private key of cert_file. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_API_TLS_KEY_FILE, which
    wins over the file. Rules: required_with=CertFile.

  controller.api.job_timeout
    How long to wait for agent responses before returning partial results.
    Go duration format (default: 30s). Type: string. Default: 30s.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_API_JOB_TIMEOUT, which wins
    over the file. Rules: omitempty,go_duration.

  controller.nats.host
    NATS server hostname to connect to. Type: string. Default: localhost.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NATS_HOST, which wins over
    the file.

  controller.nats.port
    NATS server port to connect to. Type: int. Default: 4222.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NATS_PORT, which wins over
    the file. Rules: min=1,max=65535.

  controller.nats.client_name
    Client name sent to NATS for identification. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NATS_CLIENT_NAME, which
    wins over the file.

  controller.nats.namespace
    Subject namespace prefix. Must match nats.server.namespace. Type:
    string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NATS_NAMESPACE, which wins
    over the file. Rules: omitempty,nats_name.

  controller.nats.auth.type
    Authentication type: 'none', 'user_pass', 'nkey', or 'creds'. Type:
    string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NATS_AUTH_TYPE, which wins
    over the file.

  controller.nats.auth.username
    Username for user_pass auth. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NATS_AUTH_USERNAME, which
    wins over the file.

  controller.nats.auth.password
    Password for user_pass auth. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NATS_AUTH_PASSWORD, which
    wins over the file. A secret: osapi prints it as ********.

  controller.nats.auth.nkey_file
    Path to the NKey seed file for nkey auth. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NATS_AUTH_NKEY_FILE, which
    wins over the file.

  controller.nats.auth.creds_file
    Path to a NATS credentials file (user JWT and seed) for creds auth.
    Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NATS_AUTH_CREDS_FILE, which
    wins over the file.

  controller.metrics.enabled
    Enable the metrics endpoint (default: true). Type: bool.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_METRICS_ENABLED, which wins
    over the file.

  controller.metrics.host
    Host the metrics server binds to. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_METRICS_HOST, which wins
    over the file.

  controller.metrics.port
    Port the metrics server listens on. Type: int. Default: 9090.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_METRICS_PORT, which wins
    over the file. Rules: omitempty,min=1,max=65535.

  controller.metrics.url
    Where a person opens the metrics endpoint, shown by health beside the
    bind address. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_METRICS_URL, which wins
    over the file. Rules: omitempty,http_url.

  controller.notifications.enabled
    Enable the condition watcher and notifier (default: true). Type: bool.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NOTIFICATIONS_ENABLED,
    which wins over the file.

  controller.notifications.notifier
    Notifier backend: 'log' (default). Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_NOTIFICATIONS_NOTIFIER,
    which wins over the file.

  controller.notifications.renotify_interval
    How often to re-fire active conditions (Go duration). Zero disables
    re-notification. Type: string.
    Use: In osapi.yaml, or with
    OSAPI_CONTROLLER_NOTIFICATIONS_RENOTIFY_INTERVAL, which wins over the
    file. Rules: omitempty,go_duration.

  controller.ui.enabled
    Serve the embedded UI (default: true). Type: bool.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_UI_ENABLED, which wins over
    the file.

  controller.ui.url
    Where a person opens the UI, shown by health beside the bind address.
    Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_UI_URL, which wins over the
    file. Rules: omitempty,http_url.

  controller.pki.key_dir
    Directory for controller keypair storage. Type: string. Default:
    /etc/osapi/pki.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_PKI_KEY_DIR, which wins
    over the file.

  controller.pki.auto_admit
    Admit each machine that asks to join, with no operator (dev/test only).
    Type: bool. Default: false.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_PKI_AUTO_ADMIT, which wins
    over the file.

  controller.pki.rotation_grace_period
    Grace period during key rotation where both old and new keys are
    accepted. Go duration format. Type: string. Default: 24h.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_PKI_ROTATION_GRACE_PERIOD,
    which wins over the file. Rules: omitempty,go_duration.

  controller.pki.delete_after
    Delete an admitted machine that has not reported for this long, such as
    720h. Empty is never. Go duration format. Type: string.
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_PKI_DELETE_AFTER, which
    wins over the file. Rules: omitempty,go_duration.

  controller.secrets.vaults
    The vaults that a reference such as secret://default/registry-token
    names, each with name, type, targets, key_file or key_env, and config.
    Type: list. Default: [map[key_file:/etc/osapi/secrets.key name:default
    type:nats]].
    Use: In osapi.yaml, or with OSAPI_CONTROLLER_SECRETS_VAULTS, which wins
    over the file. Rules: dive.
