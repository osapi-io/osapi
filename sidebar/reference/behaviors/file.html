Method status​

Namestatus
Verbread
DescriptionShow whether a deployed file holds what osapi wrote
DetailCompares the file on the host with the record that osapi keeps of what it deployed: in-sync when they agree, drifted when something changed the file, missing when osapi deployed the file and it is gone, and unmanaged when osapi did not deploy the path or undeployed it. A path that is a directory is refused.

Method update​

Nameupdate
Verbwrite
DescriptionDeploy an object of the object store to a path
DetailWrites the object at the path with its mode and ownership, and keeps a record of it. A template object, or content_type template, is rendered first with .Facts, .Vars and .Hostname. The record keeps the SHA-256 of the object as it was read. A file that holds the content, mode and owner already, from the same object, does not change and reports changed: false. osapi client file stale list compares the object now with that SHA-256, so it shows the deployments whose object changed since.
HTTPPUT
Route/api/node/{hostname}/file
Permissionfile:write
Commandosapi client node file update
Input typeUpdateInput
Output typeUpdateResult

Input (7)​

groupstringnopattern ^[a-z_][a-z0-9_-]*$?$Group that owns the file; left as written when empty
content_typestringnoone of raw templateHow the object is written: raw as it is, or template rendered with .Facts, .Vars and .Hostname; the object's own when empty
varsobjectnoVariables of a template, as .Vars, each as key=value
