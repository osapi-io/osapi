Method exec​

Nameexec
Verbwrite
DescriptionRun a command in a container
DetailRuns docker exec, and answers what the command wrote to standard output and to standard error, and its exit code. A command that exits with a code other than 0 is an answer, not a failure. It changes what the command changes, which osapi cannot tell, so it reports changed: true. Its permission is docker:exec, which only the admin role gets, apart from the docker:execute of start and stop. An agent with agent.command.enabled false refuses it, as it refuses a command.
HTTPPOST
Route/api/node/{hostname}/docker/{name}/exec
Permissiondocker:exec
Commandosapi client node docker exec
Input typeExecInput
Output typeExecResult
