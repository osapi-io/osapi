# Architecture

The UI's architecture is stated in the osapi-io specifications repository:
https://github.com/osapi-io/specs/blob/main/components/osapi/ui.md

This file is a pointer, not a summary. A contributor in `ui/` looks for the
architecture next to the code. Thus this file tells them where it is. A copy of
the architecture here puts it in two places again, and the specs page replaced
that copy.
